# 安全情报日报 · 2026-10-13

**今日焦点**：CISA 通告：Citrix NetScaler ADC/Gateway 在野利用的严重零日漏洞

## 漏洞与在野利用

### CISA 通告：Citrix NetScaler ADC/Gateway 在野利用的严重零日漏洞
评分 85 · 置信度 high

CISA 于 10 月 9 日更新告警，纳入 CVE-2026-107406 与已进 KEV 目录的 CVE-2026-88779，并澄清 CVE-2026-88779 与 CVE-2026-88771 可能相关，强调尽快修补 CVE-2026-88771 至 CVE-2026-88779 及 CVE-2026-107406。

**影响**：NetScaler ADC/Gateway 是大量企业、云与区块链运维环境的边界组件；零日在野利用意味着未修复设备面临即刻接管风险。

**建议**：立即升级 NetScaler 至官方修复版本；无法打补丁的设备先限制管理面暴露；核查既有访问日志与完整性，联邦机构受 BOD 时限约束。

来源：https://www.cisa.gov/news-events/alerts/2026/09/27/critical-zero-day-vulnerabilities-exploited-citrix-netscaler-adc-gateway

### SonicWall SMA 1000 关键漏洞 CVE-2026-102255（CVSS 10.0）补丁发布后仍遭 135 次利用
评分 82 · 置信度 high

新披露的 SonicWall Secure Mobile Access (SMA) 1000 预认证 SSRF 漏洞（CVE-2026-102255，CVSS 10.0）在公开披露数天内即被攻击者利用；观测到 135 次利用尝试。

**影响**：SMA 1000 是远程访问入口，被接管即等于攻击者获得内网初始立足点；未打补丁或未重启生效的设备风险极高。

**建议**：升级固件并确认修复实际生效（重启/校验版本）；核查访问日志中来自 SMA 的异常请求；限制管理面暴露。

来源：https://thehackernews.com/2026/10/critical-sonicwall-sma-1000-flaw.html

### CISA：MikroTik RouterOS 整数下溢漏洞（CVE-2026-84411，CVSS 9.8）可致远程代码执行
评分 80 · 置信度 high

CISA ICS 公告指出 RouterOS <7.24 受 CVE-2026-84411 影响，成功利用可导致远程代码执行或拒绝服务，CVSS v3 9.8，背景标注关键基础设施。

**影响**：MikroTik 在 offices、数据中心出口、机房与边缘节点广泛使用，是区块链运维网络里常见但易被忽视的边界设备；RCE 意味着整条网络路径可信度崩塌。

**建议**：升级至 RouterOS 7.24+；审计设备配置与固件完整性；将管理界面置于 VPN 或 ACL 白名单之后。

来源：https://www.cisa.gov/news-events/ics-advisories/icsa-26-272-06

### WordPress Bricksforge 插件 CVSS 10.0 漏洞遭在野利用（未认证 RCE）
评分 70 · 置信度 high

Patchstack 报告 WordPress 插件 Bricksforge 的 CVE-2026-85097（CVSS 10.0）正被在野利用，未认证攻击者可上传并执行任意 PHP 代码，实现远程代码执行。

**影响**：WordPress 站点（含大量企业官网、活动页、文档站）被攻陷后可作钓鱼载体、恶意软件分发点与内网跳板。

**建议**：立即升级 Bricksforge/停用未必要插件；对站点做文件完整性扫描；检查 Web 服务器日志中异常上传请求。

来源：https://thehackernews.com/2026/10/attackers-exploit-cvss-100-bricksforge.html

## 供应链/CI-CD

### GitHub Actions 配置缺陷被武器化：trivy-action 泄密后门植入 LiteLLM（PyPI）
评分 85 · 置信度 high

2026 年 3 月攻击者利用 aquasecurity/trivy-action 的 pull_request_target 错误配置窃取组织与仓库密钥，随后用该凭据在 PyPI 上后门化 LiteLLM。Trail of Bits 为此为 CI/CD 静态分析器 zizmor 补齐了完整 YAML anchor 支持。

**影响**：直接命中 CI/CD 供应链：一个流行扫描 Action 的错误配置即可导致密钥外泄并向下游包分发投毒，所有使用 GitHub Actions 的仓库（含区块链项目构建系统）均在暴露面内。

**建议**：在所有仓库启用 zizmor（或其同类）扫描 Actions 工作流；禁用/修正 pull_request_target 向 fork 暴露 secrets 的模式；轮换组织与仓库 secrets 并审计近期运行日志。

来源：https://blog.trailofbits.com/2026/05/22/we-hardened-zizmors-github-actions-static-analyzer/

### Tensorlake npm SDK 被 ChainDrop/Shai-Hulud 供应链攻击攻陷
评分 80 · 置信度 high

npm 包 tensorlake（TypeScript SDK）0.5.144 恶意版本在 ChainDrop / Shai-Hulud 供应链攻击中被分发，包含混淆恶意代码：收割凭据、外泄密钥、建立持久化并执行远程命令。

**影响**：Shai-Hulud 蠕虫式传播针对开发者凭据与 CI 密钥；使用受影响版本的项目其构建与云环境凭据都应视为已泄露。

**建议**：排查 lockfile 中 tensorlake@0.5.144 与相关 ChainDrop 指标；全量轮换 CI/云/npm 凭据；启用 npm 供应链检测（安装钩子/锁定审查）。

来源：https://thehackernews.com/2026/10/tensorlake-npm-package-compromised-to.html

### MALFEX：8 个恶意 npm 包累计下载 40,767 次，投放 Overlord RAT 与信息窃取器
评分 68 · 置信度 high

CloudSEK 与 Checkmarx 命名的 MALFEX 长期 npm 供应链活动中，单一攻击者自 2023 年 8 月起发布 12 个包，其中 8 个恶意包被下载 40,767 次，投放信息窃取器与 Overlord RAT。

**影响**：开发者机器与 CI 环境被植入 RAT，凭据与密钥暴露；下载量说明受影响面不小。

**建议**：审查 npm 依赖树与 typosquatting；比对已知恶意包清单并移除；轮换受影响主机凭据；启用依赖白名单/私有 registry。

### CISA 联合通告：中国背景威胁行为者以自动化工具与人工入侵组合窃取敏感数据
评分 72 · 置信度 high

CISA（AA26-281A，10 月 8 日原文）指 Integrity Technology Group 支撑的中国政府关联威胁行为者，正结合自动化扫描工具、大规模僵尸网络与手工入侵手法窃取敏感数据。

**建议**：按公告 TTP 对照自查边界暴露面与日志留存；收紧远程访问（零信任/白名单）；对可疑扫描行为建立告警规则。

来源：https://www.cisa.gov/news-events/cybersecurity-advisories/aa26-281a

## 钓鱼与社工

### FBI/USSS 警告：FortiBleed 凭据收割活动仍在活跃，已积累 86,644 台 Fortinet 设备凭据
评分 75 · 置信度 high

FBI 与特勤局警告针对互联网暴露的 FortiGate 防火墙与 SSL VPN 网关的 FortiBleed 凭据收割活动仍在持续，活动利用复用或泄露的凭据以及传统 SHA-256 口令存储方式。

**影响**：Fortinet 设备是 VPN/边界主力，凭据批量收割意味着后续大规模 VPN 入侵；弱口令存储使撞库成功率进一步升高。

**建议**：强制 MFA 并轮换所有 FortiGate/SSL-VPN 账号口令；清理复用/遗留账号；检查异常登录；升级到禁用旧式口令存储的版本。

来源：https://thehackernews.com/2026/10/fbi-warns-fortibleed-remains-active.html
