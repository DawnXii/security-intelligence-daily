Ivanti Connect Secure 列入 KEV 确认在野

CISA 于 2026-10-30 将 Ivanti Connect Secure 的 CVE-2026-118527 列入已知被利用漏洞目录（KEV），确认存在在野利用。处置要求：按厂商指引应用缓解措施、遵循 BOD 26-04 风险优先补丁与取证分诊要求，无可用缓解措施时停用产品。此前 10-14/10-17 日报报道的是该产品的另一在野缺陷，本枚 CVE 系首次入 KEV。

CVE-2026-1185272 源报道
受影响 Ivanti Connect Secure
Impact

面向互联网暴露的 Connect Secure 边界 VPN 设备构成即时失陷通道；KEV 认定在野意味着攻击者已掌握可用手段，属必须限期处置项。

Action

按 KEV/BOD 26-04 时限处置：应用 Ivanti 补丁或厂商缓解措施，无法缓解即下线；对暴露资产做取证分诊，排查既有入侵痕迹。

LXD 免私钥冒充受信任客户端

Canonical 的 LXD 与 MicroCloud 曝出 CVSS 10.0 严重缺陷：攻击者只要网络可达其 HTTPS API 并持有受信任客户端的公开证书，无需对方私钥即可登录为该客户端，进入集群并操作其中的虚拟机。来源未给出 CVE 编号、修复版本与在野利用情况。

CVSS 10.0
受影响 Canonical LXD and MicroCloud
Impact

网络暴露 LXD/MicroCloud 管理 API 的私有云与虚拟化集群面临整簇失守风险——被冒充客户端拥有什么权限，攻击者就拿到什么权限。

Action

盘点 LXD/MicroCloud 部署的 HTTPS API 暴露面与客户端证书清单，收紧可达性并轮换证书；跟踪 Canonical 安全通告及时升级（本条未含修复版本号）。

AdminNeo 存在 Cookie 属性注入

GitHub 安全公告披露 AdminNeo 4.6.0 至至少 5.5.0 存在 Cookie 属性注入（CVSS 8.2）：未净化的 X-Forwarded-Prefix 请求头可被写入 Set-Cookie，能影响该头的攻击方（透传客户端该头的反向代理、被控上游代理或中间人位置）可注入 Domain、Path、Secure 等任意 cookie 属性。修复版本 5.5.1。

CVE-2026-96631CVSS 8.2
受影响 adminneo-org/adminneo 4.6.0 through at least 5.5.0修复 5.5.1
Impact

暴露于第三方透传头场景的 AdminNeo 部署首当其冲；注入 Domain 属性会改变 cookie 生效范围，削弱会话边界保护。

Action

升级 adminneo 至 5.5.1；在入口代理过滤或覆写 X-Forwarded-Prefix 请求头，不让客户端值直接透传。

畸形 DICOM 可静默篡改 MONAILabel 推理

GitHub 公告披露 MONAILabel 服务端缺陷（CVE-2026-48705，CVSS 9.3）：未经认证的远程攻击者经 REST API 上传单个约 132 KB 的畸形 DICOM 文件，即可使服务崩溃，或静默破坏其医疗 AI 推理结果。根因是 pydicom 未校验 DS/IS 值表示，NaN 与无穷值得以穿透。修复版本 1.6.1。

CVE-2026-48705CVSS 9.3
受影响 MONAILabel server（pip 生态 monai）修复 1.6.1
Impact

运行 MONAILabel 的医疗影像 AI 环境暴露：除服务可用性受损外，推理结果被静默篡改难以察觉，可能直接影响辅助诊断判断。

Action

升级 monai 至 1.6.1；对未认证的 REST API 入口加访问控制，入库 DICOM 校验 DS/IS 字段的数值合法性。

FBI 指认 TraderTraitor 盗取币安资产

FBI 正式把逾 6 billion 美元虚拟资产被盗归因于亲朝鲜精英黑客组织 TraderTraitor——该组织亦被追踪方记作 Jade Sleet、Pressure Chollima、PUKCHONG、Slow Pisces、UNC4899。通报由 FBI 联同美国特勤局（USSS）与国税局刑事调查处（IRS-CI）共同发出，案件规模创加密盗窃纪录。

TraderTraitor17 源报道
受影响 Binance
Impact

执法口径坐实史上最大加密盗窃案的国家行为体背景，被盗资金地址进入全网拦截视野，对交易所与 DeFi 中间层的合规筛查与资金拦截构成直接压力。

North Korea17 源报道
受影响 Binance
Impact

指向交易所密钥签名环节运维环境失守——签名基础设施被控即可驱动热钱包非授权划转，对交易所与自托管运维都是同一暴露面。
