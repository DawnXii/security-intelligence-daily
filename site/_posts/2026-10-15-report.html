Cisco 邮件网关漏洞遭在野利用

Cisco 通告称攻击者正利用 Secure Email Gateway 一个严重缺陷：无需登录的发件人即可向设备操作系统写入文件。攻击者向网关发送带特制附件的邮件，成功后可进一步以 root 权限执行命令。该漏洞今日已被 CISA 列入 KEV 目录。

Impact

邮件安全网关处于通信边界且以高权限处理全量邮件，被 root 级攻陷等同于整个邮件通道失守。

Action

立即按 Cisco 通告升级至修复版本；回查网关异常文件与外联，并重置设备凭据。

PAN-OS 漏洞入 KEV 确认在野利用

Impact

PAN-OS 承载企业边界防火墙与 VPN，被在野利用的缺陷直接威胁网络入口完整性，波及海量存量设备。

Action

立即比对 PAN-OS 修复版本清单并升级；回查管理面异常登录、配置变更与外联流量。

Nextcloud 服务器遭植入网页后门

攻击者利用 Nextcloud 可选应用 Collabora Online - Built-in CODE Server 中的缺陷，在 Nextcloud 服务器上植入 webshell 获得 web 服务账号权限。三名管理员在 GitHub 报告了该问题，首次记录的攻击发生在 9 月 10 日。

供应链 / CI-CD处置 P2 · CONF high72

多数包管理器不校验仓库注入代码

Trail of Bits 测试了 25 种主流包管理器，检查其能否发现被攻陷的软件包仓库向合法包注入恶意代码。结果中不到一半默认使用可检测篡改的 lockfile，仅两个会对下载的全部软件包验证完整性。

Impact

镜像仓库一旦被入侵即可静默投毒，构建系统与 CI/CD 将无差别拉入恶意代码，属系统性供应链缺口。

Action

默认启用带完整性校验的 lockfile/签名验证；对镜像源与私有仓库出站内容做哈希一致性审计。
