MLflow 未认证服务器可被远程执行代码

GitHub 安全通告披露 CVE-2026-116692（critical，CVSS 9.8）：MLflow 在第三方 scorer 反序列化时接受请求可控的 Python 模块路径并同步导入实例化，未认证服务器上可致远程代码执行。该反序列化能力由 MLflow 3.12.0 引入，修复版本 3.17.0。

CVE-2026-116692CVSS 9.82 源报道
受影响 mlflow（pip 生态）修复 3.17.0
Impact

以未认证方式运行的 MLflow tracking server 直接暴露远程代码执行面；承载实验记录与模型工件的团队环境一旦失陷，攻击者可借调用方放置的 artifact 模块进入服务器。

Action

升级 mlflow 至 3.17.0；清查对外可达且未启用认证的 MLflow 服务，限制第三方 scorer 反序列化入口。

OAuthLib 设备码流程可被冒领令牌

GitHub 通告 CVE-2026-49272（high，CVSS 8.5）：OAuthLib 的设备授权流程中，以 grant type urn:ietf:params:oauth:grant-type:device_code 携带 bogus device_code 调用 token 端点，只要知道一个启用设备流程的有效 client ID 就能取回 bearer token，不符合 RFC 8628 第 3.4 节；修复版本 4.0.0。

CVE-2026-49272CVSS 8.5
受影响 oauthlib（pip 生态）修复 4.0.0
Impact

凡以 OAuthLib 实现设备码登录的认证服务，攻击者无需任何用户交互即可冒领 bearer token，等同绕过设备码流程的授权环节。

Action

升级 oauthlib 至 4.0.0；自查依赖该库的 IdP/CLI 登录服务是否校验 device_code 归属。
