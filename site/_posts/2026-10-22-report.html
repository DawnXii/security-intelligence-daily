PHP2Shell现攻击尝试PHP发紧急补丁

PHP 发布紧急更新修复语言自身两个严重漏洞（合称 PHP2Shell），允许无账号攻击者在 Web 服务器执行代码；修复版本为 8.5.12、8.4.27、8.3.36 和 8.2.35，PHP 团队称只有完整升级才能保护服务器。漏洞位于 PHP runtime 而非应用层，报道标题显示已出现利用尝试。

4 源报道
受影响 PHP runtime（应用无关）修复 8.5.12, 8.4.27, 8.3.36, 8.2.35
Impact

任何直接对外提供 web 请求的 PHP 站点均暴露，即使应用自身无漏洞；未打补丁的公网 PHP 服务器面临被植入 webshell/接管的风险。

Action

立即升级至 PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35；无法即刻升级的临时收敛对外暴露面，并对 PHP 服务做 webshell 与异常进程排查。

GitLab曝未授权RCE覆盖12年版本

GitLab 于 October 21 发布修复：一个未登录即可在 self-managed 服务器执行代码的漏洞，影响可回溯至 2014 年发布的 7.0 起的每个版本，标题标注 CVSS 10.0。此前 October 12 的更新仅覆盖 19.2 及以后版本，新修复版在其之上再高一档补丁——九天前打过补丁的管理者仍需再升。

受影响 GitLab self-managed 7.0（2014）以来全部版本修复 October 21 修复版本
Impact

所有 self-managed GitLab 实例（承载代码仓库与 CI/CD 管线）在未打最新补丁前面临未授权 RCE；CI/CD 失陷意味着供应链下游扩散风险。

Action

立即升级至 October 21 发布的修复版本（在 10 月 12 日补丁基础上仍需再高一档）；已在 October 12 打过 19.2+ 补丁的实例同样需要跟进本次版本。

LiteLLM遭投毒投递窃密器与后门

LiteLLM Python 包遭软件供应链攻击：1.107.0 版本经 PyPI wheel 与 Docker 镜像投递凭据窃取器和后门，SafeDep、Socket、StepSecurity、Upwind 等监测方披露。该包随后在 PyPI 被隔离（quarantined）。

2 源报道
受影响 LiteLLM 1.107.0修复 已隔离（quarantined）于 PyPI
Impact

LiteLLM 是流行 LLM 网关库，被 AI/运维管线广泛引用；拉取过受影响版本的开发机、CI 构建与容器运行环境可能已泄露 API key、令牌与凭据，并植入持久后门。

Action

立即排查是否安装过 LiteLLM 1.107.0（PyPI wheel 或 Docker 镜像），隔离环境取证、轮换该环境全部凭据与密钥，改用隔离后的干净版本重建依赖锁定，并对构建主机做威胁狩猎。
