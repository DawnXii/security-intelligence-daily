01漏洞与在野利用

今日焦点CONF high92

CISA：Ivanti Connect Secure 认证绕过零日 CVE-2026-104935 已在野利用，列入 KEV

CISA 确认 Ivanti 披露的 CVE-2026-104935 正被威胁行为者主动利用，影响 Ivanti Connect Secure 25.1.1.1 及更早、25.1.2.2 及更早、22.8R2.4 及更早版本。该零日认证绕过漏洞允许远程未认证攻击者执行任意命令，被用于凭据窃取和数据外泄。CISA 已于 2026 年 10 月 13 日将其加入 KEV 目录，并敦促受影响组织立即升级至最新版本。

Impact

VPN 集中入口被未认证 RCE 打通后，攻击者可直接窃取凭据并外传内部数据，等于绕过整个边界防线；对以 ICS 做远程接入的企业构成即时失陷风险。

Action

立即将 Ivanti Connect Secure 升级到最新受支持版本并核对 Ivanti 官方安全通告；无法马上打补丁的实例应临时收敛暴露面，并审计凭据窃取与数据外泄迹象。

Volexity：攻击者链式利用 Ivanti Connect Secure 三个零日获取 root，第三个补丁仍未发布

Volexity 于 10 月 13 日披露，有攻击者将 Ivanti Connect Secure VPN 设备上的三个零日漏洞链式利用，实现未登录以 root 执行命令。Ivanti 已修复其中两个漏洞并敦促受影响版本客户立即行动，但第三个漏洞的补丁仍未发布。

Impact

root 级未认证命令执行意味着 VPN 边界可被完全接管；未修复的第三个零日使单纯打补丁不足以止血，已入侵设备可能保留隐藏后门。

Action

对 ICS 设备立即应用现有补丁、持续跟踪第三个漏洞的修复发布；高危环境建议重置设备、轮换所有经由 VPN 的凭据，并做完整性核查而非仅看版本号。

SonicWall SMA 1000 严重漏洞 CVE-2026-102255（CVSS 10.0）披露数日即遭在野利用

威胁行为者在 SonicWall Secure Mobile Access (SMA) 1000 关键漏洞公开披露后数天内即开始利用。该漏洞编号 CVE-2026-102255，CVSS 10.0，为预认证服务器端请求伪造（SSRF），可迫使设备按攻击者意图发出请求。

Impact

SMA 1000 是远程访问入口，预认证 SSRF 可被用于打穿内网管理服务与横向探测；披露到利用的窗口极短，暴露中的 SSL VPN 设备面临即时风险。

Action

尽快升级 SonicWall SMA 1000 固件至修复版本；修复前收敛管理接口暴露、审查设备异常出站请求日志，并对经由 SMA 的账户强制重置凭据。

WordPress 插件 Bricksforge CVSS 10.0 漏洞 CVE-2026-85097 遭在野利用，未认证 RCE

Patchstack 报告 WordPress 插件 Bricksforge 的最高危漏洞 CVE-2026-85097（CVSS 10.0）已在野被主动利用，未认证攻击者可上传并执行任意 PHP 代码，导致远程代码执行。

Impact

WordPress 承载大量企业官网与电商，未认证上传执行 PHP 意味着即时 Webshell 落地，站点可被用于挂马、钓鱼和凭据窃取，共享主机的横向风险也高。

Action

立即升级 Bricksforge 至修复版本或临时停用该插件；对站点做 webshell 与异常管理员账户排查，检查上传目录与文件哈希基线，回滚可疑改动并轮换站点凭据。

CISA/ICS 通告：MikroTik RouterOS 预认证整数下溢 CVE-2026-84411（CVSS 9.8）可致 RCE

CISA 通告 MikroTik RouterOS 7.24 之前版本存在 CVE-2026-84411，CVSS v3 9.8。其 web 管理服务的 HTTP 请求体处理存在整数下溢，可在认证前被远程触发，利用后可实现任意代码执行或拒绝服务，涉及通信与信息技术关键基础设施部门。

Impact

RouterOS 广泛用于 ISP、机房和小企业边界网络，管理面预认证 RCE 等于把整个网络出口交给攻击者；自建节点与小型 IDC 的网络边界风险尤甚。

Action

升级 RouterOS 至 7.24 及以上；无法立即升级时禁用面向公网的 web 管理服务、改用 IP 白名单或隧道化管理，并核查设备配置是否被篡改。

漏洞与在野利用CONF high75

SAP Cloud SDK for Python 缺陷可把 OAuth2 客户端凭据发往攻击者控制的服务器

SAP 于 10 月 13 日发布安全通告：Cloud SDK for Python 存在缺陷，可将应用的 OAuth2 客户端凭据发送至攻击者控制的服务器。受影响对象为使用 SAP Business Technology Platform (BTP) 的多租户应用，攻击前提是其能控制租户子域。

Impact

OAuth2 client credentials 一旦外泄即等同机器身份失窃，可静默访问 BTP 服务与下游 API；对把云平台凭据托管在 SDK 中的企业是源头级风险。

Action

按 SAP 安全通告升级 Cloud SDK for Python；审计多租户应用中的租户子域来源与异常出站目标，轮换受影响应用的 OAuth2 客户端凭据，并对子域输入做校验加固。

AhsayCBS 备份系统漏洞遭在野利用：部署 Webshell 与 XMRig 挖矿

威胁行为者正利用 AhsayCBS 备份工具近期披露的两个缺陷夺取设备控制权，部署 webshell 和 XMRig 加密货币挖矿程序。已知细节含 CVE-2026-105133（CVSS v4 5.5），为 checkSysPwd() 函数中的不当认证漏洞。

Impact

Action

升级 AhsayCBS 修复 CVE-2026-105133 等披露缺陷；排查备份服务器上异常 webshell、计划任务与 XMRig 进程，收敛备份管理端口的公网暴露并启用强认证。

02供应链/CI-CD

供应链/CI-CDCONF high86

npm 包 tensorlake 遭 ChainDrop/Shai-Hulud 供应链攻击投毒（0.5.144）

Tensorlake 官方 TypeScript SDK 的 npm 包 "tensorlake" 在 ChainDrop / Shai-Hulud 供应链攻击中被入侵，恶意版本 0.5.144 包含混淆恶意软件，可收割凭据、外泄密钥、建立持久化并执行远程下发的代码（Socket 披露）。

Impact

该 SDK 面向沙箱与云服务开发，被 CI/CD、开发机和容器构建拉取后，凭据与密钥会随构建环境批量泄露，形成蠕虫式二次扩散；使用它的云/加密基础设施项目风险尤其高。

Action

排查所有依赖 tensorlake 的项目，移除 0.5.144 并更新至安全版本；对 CI runner 与开发机做凭据轮换（npm/GitHub token、云密钥），并检查持久化与远程代码执行痕迹。

Docker Hub 修复存在两年的越权缺陷：可以另一用户身份推送/拉取/删除镜像

Docker Hub 存在一处缺陷，允许一个用户以另一个用户的身份推送、拉取或删除镜像。Docker 已于 9 月 30 日修复，并表示没有证据显示该缺陷被利用；缺陷位于把个人账户转换为组织账户的功能中，Docker 在 10 月 12 日的安全通告中做了说明。

Impact

镜像仓库是容器与节点软件分发链的根信任点，若被利用可造成镜像投毒或删除；本案已修复且未见利用，但暴露了低频账户转换路径缺乏审计的结构性问题。

Action

对使用 Docker Hub 组织账户的仓库复核近期推送/删除审计日志与镜像摘要一致性；CI 中固定基础镜像 digest，关键镜像启用签名校验，避免依赖可变 tag。

03重大事件

重大事件CONF high80

CISA/AA26-281A：中国背景威胁组织结合自动化扫描、僵尸网络与手工渗透窃取敏感数据

CISA 通告：受 Integrity Technology Group 支持的中国政府背景威胁行为者，正结合自动化扫描工具、大规模僵尸网络和手工渗透技术，针对全球组织（含美国关键基础设施部门）窃取敏感数据。其手法包括漏洞利用、跨站脚本攻击、对 Microsoft Exchange 服务器密码喷洒，通过 VPN 软件建立持久化，并用脚本外传邮件和凭据。

Impact

该 TTP 组合（扫描+僵尸网络+密码喷洒+VPN 持久化）直接针对企业边界与邮件/VPN 基础设施，属于高容量、低门槛的批量入侵模式，任何暴露 Exchange 与 VPN 的机构都在打击范围内。

Action

按通告排查 Exchange 密码喷洒迹象与异常访问；对 VPN 接入全面启用强 MFA 并审计可疑持久化；部署对自动化扫描流量的检测，收敛面向互联网服务的暴露面。
