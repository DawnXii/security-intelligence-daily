MCP Toolbox 可外泄主机文件

NVD 于 2026-10-26 收录 CVE-2026-93328，评分 9.3：Google Cloud MCP Toolbox for Databases（googleapis/mcp-toolbox）versions 1.2.0 through 1.4.0 的 cloud-storage source 同时存在路径穿越与缺失授权，未认证远程攻击者通过构造的 tool invocation 参数即可把主机文件外泄到外部 Google Cloud Storage 桶，并覆写任意本地文件。

CVE-2026-93328CVSS 9.3
受影响 googleapis/mcp-toolbox versions 1.2.0 through 1.4.0
Impact

暴露人群是网络可达的 MCP Toolbox 部署，尤其是配置了 cloud-storage source 的推理与数据服务；来源确认的后果是主机文件被外送与本地文件被任意覆写。

Action

核对 googleapis/mcp-toolbox 版本是否落在 1.2.0 through 1.4.0，升级到厂商修复版本；同时限制 cloud-storage source 可读写路径与可访问的 Google Cloud Storage 桶，按未授权可达的口径排查存量资产。

Pillow FPX 解码堆溢出可致执行

GitHub 安全公告 GHSA-5x8w-8jj5-q52h（CVE-2026-112398）定级 critical：Pillow 的 FlashPix (FPX) JPEG-tile 解码器存在堆缓冲区溢出，应用只要用 Image.open() 打开一个精心构造的文件就可能被任意代码执行。由于该文件是按内容（OLE2 magic）而非扩展名被识别，任何打开或给不可信上传做缩略图的服务都在受影响范围内；修复版本为 13.0.0。

CVE-2026-112398

Action

升级到 pillow 13.0.0；排查所有以 Image.open() 接收不可信上传的服务面，公告中 CVSS 数值未给出（CVSS 0），按 critical 等级排修复优先级。
